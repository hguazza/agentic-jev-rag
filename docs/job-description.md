# Job description: AI/ML Engineer, Internal Platforms (Building the AI Recruiter)

The role this project is built to demonstrate fit for.

Help architect and ship the next generation of autonomous AI recruiting agents.

We are onboarding a full-time AI/ML Engineer, Internal Platforms at micro1 to build core agent intelligence, orchestration loops, and real-time candidate assessment workflows. In this seat, you will experiment with frontier foundation models, engineer complex agent tool-calling pipelines, design production RAG architectures, and deploy scalable FastAPI services on AWS.

## The breakdown

- **Role:** AI/ML Engineer, Internal Platforms
- **Type:** Full-time, 100% Remote
- **Compensation:** $130,000 – $160,000 Base Salary + Equity + Performance Bonus (Full benefits including 100% health premium reimbursement, 401(k) match)
- **Core stack:** Python, LLMs, LangChain / LangGraph / LlamaIndex, FastAPI, AWS, RAG & Evaluation Harnesses

## What you'll do

- Design and iterate on autonomous multi-agent workflows, prompt chains, tool calling, and RAG architectures for the micro1 recruiting agent.
- Develop scalable, low-latency backend microservices and APIs in Python using FastAPI.
- Implement rigorous evaluation pipelines to continuously benchmark model reasoning, conversational fidelity, and assessment accuracy.
- Deploy, monitor, and scale AI microservices on cloud infrastructure (AWS).
- Work closely with product leads to rapidly translate recruiting challenges into working autonomous systems.

## What you bring

- Strong production software engineering in Python and FastAPI.
- Proven track record building and shipping production applications with LLMs, tool calling, and agent frameworks (LangGraph, LangChain, or LlamaIndex).
- Hands-on experience with cloud platforms (AWS preferred).
- Deep understanding of RAG architectures, prompt optimization, vector databases, and deterministic model evaluation.
- Experimental mindset with a drive to ship customer-facing features fast.
